股票数据 ChatBI 知识库（分析思路 Tips 与 SQL 示例）

数据来源：MySQL 表 stock_daily（股票历史日线行情）。
覆盖股票：贵州茅台(600519.SH)、五粮液(000858.SZ)、国泰君安(601211.SH)、中芯国际(688981.SH)。
实际数据范围以查询结果为准，不保证更新到今天。仅允许只读查询。


Q1：对比两只股票在某一年（或某一时间段）的涨跌幅，应该怎么算？

A1：调用 stock_analysis 固定分析工具，mode=interval_return。
示例参数：{"mode":"interval_return","ts_codes":["600519.SH","000858.SZ"],"start_date":"2025-01-01","end_date":"2025-12-31"}
工具按每只股票区间内实际首末交易记录计算 (末日收盘价/首日收盘价-1)×100%。
同时展示首末取值日期和观测天数；不能把单日涨跌幅相加。只有一条行情时无法计算区间涨跌幅。
使用库内收盘价，不额外做复权或总回报调整。不要生成 CTE、窗口函数或子查询。

Q2：对比多只股票每个月末的收盘价走势，怎么查询？

A2：调用 stock_analysis，mode=monthly_close。
示例参数：{"mode":"monthly_close","ts_codes":["600519.SH","000858.SZ"],"start_date":"2025-01-01","end_date":"2025-12-31"}
每只股票每月取指定区间内最后一条行情，展示实际日期及收盘价，并按股票分系列作图。
MAX(close) 是最高价，不能代替月末价。未结束月份或缺少行情的月份，仅代表截至可用日期。


Q3：统计某段时间内各只股票的平均日涨跌幅并排序，怎么写？

A3：
思路：直接对 pct_chg 按股票分组求 AVG，并可同时给出区间内最大单日涨幅/跌幅，最后排序。
示例 SQL（2025 年 1 月）：
SELECT stock_name,
       ROUND(AVG(pct_chg), 2) AS avg_pct_chg,
       ROUND(MAX(pct_chg), 2) AS max_up,
       ROUND(MIN(pct_chg), 2) AS max_down
FROM stock_daily
WHERE trade_date BETWEEN '2025-01-01' AND '2025-01-31'
GROUP BY ts_code, stock_name
ORDER BY avg_pct_chg DESC;


Q4：查询某只股票成交量（或成交额）最大的前 N 个交易日，怎么写？

A4：
思路：按 vol（成交量）倒序排列，用 LIMIT 取前 N 条，同时带出当天收盘价和涨跌幅辅助解读。
示例 SQL（中芯国际成交量 Top 10）：
SELECT trade_date, stock_name, vol, amount, close, pct_chg
FROM stock_daily
WHERE stock_name = '中芯国际'
ORDER BY vol DESC
LIMIT 10;


Q5：查询某只股票在一段时间内的最高/最低/平均收盘价，以及极值出现的日期，怎么写？

A5：
思路一：用聚合函数直接算极值与均值：
SELECT stock_name,
       ROUND(MAX(close), 2) AS max_close,
       ROUND(MIN(close), 2) AS min_close,
       ROUND(AVG(close), 2) AS avg_close
FROM stock_daily
WHERE stock_name = '贵州茅台'
  AND trade_date BETWEEN '2025-01-01' AND '2025-06-30'
GROUP BY ts_code, stock_name;
思路二：要取最高收盘价出现的具体日期，按 close 倒序取第一条：
SELECT trade_date, close
FROM stock_daily
WHERE stock_name = '贵州茅台'
  AND trade_date BETWEEN '2025-01-01' AND '2025-06-30'
ORDER BY close DESC
LIMIT 1;
（查最低收盘价日期时改为 ORDER BY close ASC。）


Q6：统计某段时间各股票的上涨天数、下跌天数和上涨日占比，怎么查询？

A6：调用 stock_analysis，mode=daily_stats。
示例参数：{"mode":"daily_stats","ts_codes":["600519.SH","000858.SZ"],"start_date":"2025-01-01","end_date":"2025-12-31"}
分别统计 pct_chg 大于 0、小于 0、等于 0 的天数。上涨日占比的分母包含平盘日。
空值或重复交易日期会停止计算，不静默改变分母；该比例不代表未来获利概率。


Q7：指标口径与 SQL 编写易错点 Tips

A7：
1. pct_chg 是「单日」涨跌幅（百分比，基于前收盘价 pre_close）。计算区间累计涨跌幅时，
   不能把每日 pct_chg 直接相加，必须用区间首末收盘价（first/last close）计算，
   本工具采用区间首末收盘价口径。
2. `change` 是 MySQL 保留字（涨跌额），SQL 中出现时必须加反引号：`change`。
3. vol 成交量单位是「手」（1 手 = 100 股）；amount 成交额单位是「千元」，
   输出结论时注意单位换算，不要直接说成「元」或「股」。
4. 非交易日无数据；按日/周/月聚合时，日期口径要落在实际交易日上，
   月末取值使用 Q2 的 stock_analysis 工具。
5. 股票名称必须写 stock_name 中登记的全称，如「贵州茅台」「中芯国际」，
   不要写成「茅台」「中芯」；也可用 ts_code 精确过滤（如 '600519.SH'）。
6. 日期过滤一律用 trade_date，字符串格式 'YYYY-MM-DD'，
   如 WHERE trade_date BETWEEN '2025-01-01' AND '2025-03-31'。
7. 为便于自动可视化，查询结果尽量让第一列为分类或日期，其余列为数值列；
   多只股票月末对比使用 stock_analysis，它会按代码生成独立系列。
8. 只允许对 stock_daily 表做 SELECT，禁止生成 INSERT/UPDATE/DELETE 等写操作语句。
